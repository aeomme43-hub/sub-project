# 이미지 폴더

이 폴더에는 웹사이트에서 사용할 이미지 파일들을 저장합니다.

## 필요한 이미지 파일들:

1. **app1.png** - 첫 번째 어플 아이콘 (100x100 픽셀 권장)
2. **app2.png** - 두 번째 어플 아이콘 (100x100 픽셀 권장)
3. **app3.png** - 세 번째 어플 아이콘 (100x100 픽셀 권장)
4. **default-app.png** - 기본 어플 아이콘 (새로운 어플 등록 시 사용)

## 이미지 추가 방법:

1. 원하는 이미지를 이 폴더에 저장하세요
2. 파일 이름을 위의 이름과 일치시키세요
3. 이미지 크기는 100x100 픽셀을 권장합니다
4. PNG 또는 JPG 형식을 사용하세요

## 임시 사용:

이미지가 없는 경우, 온라인에서 무료 아이콘을 다운로드하거나,
다음 URL에서 임시 이미지를 사용할 수 있습니다:

- https://via.placeholder.com/100x100?text=App1
- https://via.placeholder.com/100x100?text=App2
- https://via.placeholder.com/100x100?text=App3
