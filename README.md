# SUB - 어플 및 장소 후기 웹사이트

이 프로젝트는 어플과 오프라인 장소에 대한 후기를 공유할 수 있는 웹사이트입니다.

## 프로젝트 구조

```
sub-project/
├── index.html          # 메인 HTML 파일
├── css/
│   └── style.css      # 스타일시트 파일
├── js/
│   └── script.js      # 자바스크립트 파일
├── images/            # 이미지 파일 폴더
│   ├── app1.png       # 어플 아이콘 1
│   ├── app2.png       # 어플 아이콘 2
│   ├── app3.png       # 어플 아이콘 3
│   └── default-app.png # 기본 어플 아이콘
└── README.md          # 이 파일
```

## 주요 기능

### 1. 네비게이션 바
- **SUB** 브랜드 로고
- **온라인(어플후기)** 버튼
- **오프라인(지도별 장소 후기)** 버튼
- **+** 등록 버튼

### 2. 온라인 섹션 (어플 후기)
- 어플 아이콘 슬라이드 쇼
- 구글 플레이스토어 및 애플 스토어 링크
- 어플 이름 검색 기능
- 어플 클릭 시 후기 확인
- 별점 및 텍스트 후기 표시

### 3. 오프라인 섹션 (지도별 장소 후기)
- 세계지도 (대륙 > 나라 > 도시 계층 구조)
- 지역 검색 기능 (대륙, 나라, 도시, 장소)
- 도시 선택 시 해당 장소 표시
- 장소 클릭 시 후기 확인
- 별점 및 텍스트 후기 표시

### 4. 후기 등록 시스템
- 어플 후기 등록 폼
- 장소 후기 등록 폼
- 별점 선택 (1-5점)
- 텍스트 후기 작성
- 실시간 후기 추가

## 사용 방법

### 1. 웹사이트 실행
```bash
# 브라우저에서 index.html 파일을 직접 열기
# 또는 로컬 서버 실행 (권장)
```

### 2. 이미지 준비
`images/` 폴더에 어플 아이콘 이미지를 추가하세요:
- `app1.png`, `app2.png`, `app3.png`
- 권장 크기: 100x100 픽셀
- 형식: PNG 또는 JPG

### 3. 웹사이트 사용
1. **네비게이션 바**에서 원하는 섹션 선택
2. **온라인 섹션**: 어플 슬라이드에서 어플 클릭 후기 확인
3. **오프라인 섹션**: 지도에서 대륙 > 나라 > 도시 선택 후 장소 후기 확인
4. **+ 버튼** 클릭으로 새로운 후기 등록

## 코드 설명

### HTML (index.html)
- **네비게이션 바**: 웹사이트의 메인 메뉴
- **섹션**: 온라인/오프라인 컨텐츠 영역
- **모달**: 후기 확인 및 등록 팝업창
- **폼**: 후기 등록을 위한 입력 폼

### CSS (css/style.css)
- **반응형 디자인**: 모바일/데스크톱 호환
- **슬라이드 효과**: 어플 카드 슬라이드 애니메이션
- **모달 스타일**: 팝업창 디자인
- **폼 스타일**: 입력 폼 디자인

### JavaScript (js/script.js)
- **데이터 관리**: 어플 및 장소 데이터 저장
- **네비게이션**: 섹션 전환 기능
- **슬라이드**: 어플 카드 슬라이드 기능
- **검색**: 어플 및 지역 검색 기능
- **모달**: 후기 확인 및 등록 팝업 제어
- **폼 처리**: 후기 등록 및 데이터 업데이트

## 커스터마이징

### 어플 데이터 추가
`js/script.js`의 `appsData` 배열에 새로운 어플 정보 추가:

```javascript
{
    id: 4,
    name: "새로운 어플",
    icon: "images/app4.png",
    googlePlay: "구글플레이URL",
    appleStore: "앱스토어URL",
    reviews: []
}
```

### 장소 데이터 추가
`js/script.js`의 `locationsData` 배열에 새로운 장소 정보 추가:

```javascript
{
    id: 4,
    name: "새로운 장소",
    city: "도시이름",
    country: "나라이름",
    continent: "asia",
    reviews: []
}
```

## 주의사항

- 현재 버전은 브라우저의 로컬 스토리지를 사용하지 않으므로 페이지 새로고침 시 데이터가 초기화됩니다.
- 실제 서비스에서는 백엔드 서버와 데이터베이스가 필요합니다.
- 이미지 파일은 직접 준비해야 합니다.
